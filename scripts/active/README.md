# Scripts Activos

Este directorio contiene scripts de utilidad que pueden ser necesarios para tareas específicas en la aplicación.

## Descripción de los scripts

### Facturas
- `create-invoice-direct.cjs` - Script para crear facturas directamente en la base de datos. Este script contiene lógica importante para la creación de facturas y puede servir como referencia para futuras implementaciones en la lógica principal.

## Uso seguro

Estos scripts deben utilizarse solo cuando sea necesario y con comprensión de sus efectos. Siempre que sea posible, se debe preferir utilizar la interfaz de la aplicación para realizar estas operaciones.
